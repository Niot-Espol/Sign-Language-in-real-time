# Documentación de entrega

- `manual_usuario.pdf`: se agrega al finalizar la interfaz, incluyendo instalación, captura de datos, ejecución y solución de problemas.
- `poster_cientifico/`: fuente editable y recursos gráficos del póster.
- `evidencias/`: fotografías autorizadas y bitácora del proyecto.

Los archivos `.gitkeep` permiten conservar las carpetas mientras aún están vacías.
