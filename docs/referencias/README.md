# Referencias visuales

Antes de cada sesión agrega aquí una fotografía clara de la postura estándar, con buena iluminación y sin oclusiones. Usa estos nombres:

- `comer.jpg`
- `papa.jpg` (referencia de la etiqueta `papá`)
- `ir.jpg`
- `bien.jpg`

Todas las personas del equipo deben imitar la misma orientación y configuración de mano. No guardes una ráfaga hasta comprobar visualmente que aparecen los 21 landmarks.
