# Sign-Language-in-real-time
Es un sistema en Python que usa OpenCV y MediaPipe para capturar los 21 puntos clave de la mano mediante una cámara web y traducirlos al instante con Machine Learning. Identifica entre 10 y 20 señas estáticas a más de 25 FPS y muestra la traducción en una interfaz visual con voz integrada.
